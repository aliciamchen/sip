# Figures

The manuscript's figures are generated by the Python scripts in `scripts/`
(files prefixed with `_` are shared helpers, not entry points), all styled
through the repo-root `plot_style.py`. Output is split by consumer:

- `panels/` — components assembled by hand in Illustrator: `results/` holds the
  per-study results rows and `legends/` the shared standalone legends (both from
  `make figures-panels`, with the Study 3 per-domain view from
  `make figures-nonfood-domains`), and `schematic/` holds the method-figure
  panels (`make figures-schematic`).
- `si/` — finished figures included directly by the manuscript
  (`make figures-lm-si`, `figures-si-scenarios`, `figures-si-prior-posterior`,
  and `figures-si-prereg-predictions`).
- `figure_data/` — cached inputs for the schematic panels.
- `model-eqs/` — hand-authored equation glyphs placed in the schematic figure.

Only PDFs are committed; each script also writes a gitignored PNG preview
beside each PDF.
