# food_inv-desire_intimacy_noalt

This is the no-alternatives-shown variant of the desire (reward) inference experiment. Participants see the actor's chosen action but are not shown the other actions the actor could have taken; the cognitive model correspondingly uses an LM-generated counterfactual action set.
