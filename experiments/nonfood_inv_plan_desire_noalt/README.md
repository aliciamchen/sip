# nonfood_inv_plan_desire_noalt

No-alternatives-shown variant of the desire (reward) inference experiment, non-food scenarios. Participants see the actor's chosen action but are not shown the other actions the actor could have taken; the cognitive model correspondingly uses an LM-generated counterfactual action set.
